# VocalJourney

> "My voice was not a natural gift — it was something I developed through training and discipline."
> — Morgan Freeman

This is a personal space for developing my authentic voice. It covers everything from breath mechanics to pitch training, with room for daily logs, session recordings, curated resources, and scripts that provide objective feedback.

## Goals

1. **Project my voice properly** — breath support, resonance, clarity at distance
2. **Sing properly** — pitch accuracy, tone quality, breath control, range development

## What's Here

| Directory | Purpose |
|---|---|
| [`exercises/`](exercises/) | Step-by-step drills for projection and singing |
| [`journal/`](journal/) | Daily session logs and a reusable template |
| [`recordings/`](recordings/) | Notes and metadata for local audio recordings |
| [`resources/`](resources/) | Curated links to coaches, tools, and references |
| [`scripts/`](scripts/) | Python tools for pitch, volume, and progress analysis |

## How to Use This Repo

1. **Before each session** — pick 1-2 exercises from `exercises/`, decide what to record
2. **During the session** — work the exercises, record locally, take quick notes
3. **After the session** — fill out a journal log in `journal/logs/`, add recording notes in `recordings/sessions/`
4. **Weekly** — run `scripts/recommend.py` to get exercise suggestions based on recent logs

## Guiding Philosophy

Progress is built on consistent, deliberate practice — not raw talent. Every session logged, every recording noted, every honest assessment of what felt hard moves the needle forward.

Start where you are. Track everything. Adjust constantly.
