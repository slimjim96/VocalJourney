# Exercises

Two tracks: **projection** and **singing**. They share the same foundation — breath — so expect overlap.

## Suggested Weekly Schedule

| Day | Focus | Time |
|---|---|---|
| Mon | Projection: Diaphragm Breathing + Resonance | 20 min |
| Tue | Singing: Scales + Pitch Matching | 20 min |
| Wed | Projection: Consonant Articulation | 15 min |
| Thu | Singing: Breath Control + Sustained Notes | 20 min |
| Fri | Both: Free practice, apply what you've learned | 30 min |
| Sat | Singing: Vibrato Foundation | 15 min |
| Sun | Rest or light humming only | — |

## Exercise File Format

Each exercise file follows this structure:

- **Goal** — what you're training and why
- **Duration** — recommended time per session
- **Instructions** — numbered, step-by-step
- **Common Mistakes** — what to watch for

## Tracks

- [`projection/`](projection/) — Voice projection, breath support, articulation
- [`singing/`](singing/) — Pitch, tone, range, breath, vibrato
