# Projection Exercises

Voice projection is not about being loud — it's about being *heard*. The goal is efficient breath-to-sound conversion: supported airflow, forward resonance placement, and crisp articulation.

## Exercises

1. [Diaphragm Breathing](diaphragm-breathing.md) — the engine behind everything
2. [Resonance Placement](resonance-placement.md) — directing sound forward and out
3. [Consonant Articulation](consonant-articulation.md) — clarity at distance

## Progression

Start with breathing every session before any other exercise. You cannot build projection on shallow breath.

Week 1-2: Breathing only
Week 3-4: Breathing + Resonance
Week 5+: All three, rotating emphasis
